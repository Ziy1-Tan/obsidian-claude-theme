# Changelog

## 0.2.0

- Rename the theme from Claude-Like to Obsidian Claude Theme. Existing installations should install it under the new name and select it in Settings → Appearance → Themes.
- Align light and dark palettes with the Claude product website, using neutral backgrounds and clay accents.
- Use body-colored links with clay underlines and callouts with 16px corners, full borders, and tinted backgrounds.
- Adjust syntax colors for contrast against code backgrounds and consolidate shared CSS rules.
- Replace `demo.md` with `theme-preview.md`, featuring English and Chinese text, code, links, callouts, tables, and tasks.
- Replace the old images with `theme-preview-light.png` and `theme-preview-dark.png` at the repository root.
- Simplify installation instructions and add shell commands to create the theme folder and download its files.
- Remove the `docs/` and `images/` directories.

## 0.1.0

- Initial Claude-Like theme release with light and dark modes.
